SOURCE CODE

Format Fighter includes two libraries under the GNU Lesser General Public License (LGPL): FFmpeg 8.1.3 (LGPL 2.1 or later, built without GPL or non-free parts) and LAME 4.0 (LGPL 2.0 or later).

They are inside the app as separate dynamic libraries (Format Fighter.app/Contents/Frameworks), which you can replace with your own builds. Here is their complete source code, the change Format Fighter makes to FFmpeg, and the scripts used to build them, for every version of the app.

WHAT'S INSIDE

  • FFmpeg 8.1.3: tag n8.1.3, commit 1041abdc962f4cc4f394aa8de9dc5236c0c3b9e7, unchanged.
  • LAME 4.0, as published by the LAME project.
  • The libraries built into FFmpeg (BSD licences): libvpx 1.17.0, Opus 1.6.1, libogg 1.3.6, libvorbis 1.3.7 and dav1d 1.5.4.
  • Format Fighter's one change to FFmpeg (ffmpeg-movenc-hevc-sync-group.patch): the MP4/MOV muxer writes the HEVC "sync" sample group, so Apple's players can seek in copied HEVC video.
  • The build scripts (build.sh, fetch.sh, versions.sh), with the exact configure options, and a README with the steps to rebuild and replace the libraries.
  • The texts of the LGPL 2.1 and 2.0.
