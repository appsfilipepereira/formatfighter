# Format Fighter website

The website of Format Fighter, a macOS menu bar file converter: privacy policy, support and
the source code of the LGPL libraries the app includes. Plain HTML and CSS, served by GitHub
Pages. The app's own code is not here.

The arcade font (`fonts/FormatFighterArcade-Regular.ttf`) is a modified version of Press Start 2P,
under the SIL Open Font License 1.1 (`fonts/OFL.txt`).
