CÓDIGO-FONTE

O Format Fighter inclui duas bibliotecas sob a GNU Lesser General Public License (LGPL): FFmpeg 8.1.3 (LGPL 2.1 ou posterior, compilado sem partes GPL nem "non-free") e LAME 4.0 (LGPL 2.0 ou posterior).

Estão dentro da app como bibliotecas dinâmicas separadas (Format Fighter.app/Contents/Frameworks), que podes substituir por versões tuas. Aqui está o código-fonte completo delas, a alteração que o Format Fighter faz ao FFmpeg e os scripts usados para as compilar, para cada versão da app.

O QUE ESTÁ LÁ DENTRO

  • FFmpeg 8.1.3: tag n8.1.3, commit 1041abdc962f4cc4f394aa8de9dc5236c0c3b9e7, com a alteração descrita abaixo.
  • LAME 4.0, tal como publicado pelo projeto LAME.
  • As bibliotecas compiladas dentro do FFmpeg (licenças BSD): libvpx 1.17.0, Opus 1.6.1, libogg 1.3.6, libvorbis 1.3.7 e dav1d 1.5.4.
  • A única alteração do Format Fighter ao FFmpeg (ffmpeg-movenc-hevc-sync-group.patch): o gravador de MP4/MOV escreve o grupo de amostras "sync" do HEVC, para os leitores da Apple conseguirem saltar no vídeo HEVC copiado.
  • Os scripts de compilação (build.sh, fetch.sh, versions.sh), com as opções exatas, e um README (em inglês) com os passos para recompilar e substituir as bibliotecas.
  • Os textos da LGPL 2.1 e 2.0.

O código do próprio Format Fighter não está abrangido pela LGPL e não é publicado. Para perguntas sobre este código-fonte, escreve para support@formatfighter.com.
